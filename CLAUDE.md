# Chutti's Dental & Wellness Center — Website

Source-of-truth documents (always follow them):
- docs/narrative.md — what the site says: positioning, copy rules, facts, services, reviews, FAQs
- docs/build-spec.md — how it's built: tech stack (Part A), visual story and motion (Part B), asset manifest (Part C)

Rules:
- Never invent facts, numbers, claims, reviews or services. If something isn't in the docs, ask.
- Content/claims conflict → narrative.md wins. Visual/motion/engineering conflict → build-spec.md wins.
- Missing illustrations or photos → clearly labelled placeholder + list it in handoff notes. Never ship a placeholder silently.
- Work phase by phase. Stop at the end of each phase for my review before continuing.
- When the docs change, re-read them before continuing.
